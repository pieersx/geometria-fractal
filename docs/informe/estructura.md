# Estructura del informe (formato APA)

Basada en lo que pide la rúbrica. Cada capítulo de módulo sigue el mismo esquema.

1. Portada
2. Índice
3. Presentación o resumen
4. Capítulo 1. Introducción a la geometría fractal (autosimilitud, dimensión fraccionaria, historia)
5. Capítulo 2. Conjuntos de escape: Mandelbrot y Julia
6. Capítulo 3. Sistemas de funciones iteradas y Chaos Game
7. Capítulo 4. L-systems
8. Capítulo 5. Terreno fractal (fBm / diamond-square)
9. Capítulo 6. Dimensión fractal y box-counting
10. Descripción de la aplicación gráfica
11. Conclusión
12. Bibliografía (mínimo 2 artículos de revista especializada)
13. Anexo. Bitácora de uso de IA (tema, herramienta, día y hora)

## Esquema de cada capítulo de módulo

- Descripción del algoritmo o método
- Fortalezas
- Debilidades
- Caso práctico de aplicación
- Captura y enlace a la demostración en la app
